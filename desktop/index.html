Join by room name

Both players use the same room server, name and password. The host approves each guest. Password spaces and capitals count. Room mode defaults to stun:stun.l.google.com:19302; change the STUN URLs below to use your own server. TURN is used only if you explicitly configure it. No hosted room service or relay is supplied.

Manual connection settings

No relay or account needed. Allow the chosen TCP port through the host firewall. For internet guests, forward it to this computer's local IPv4 address in your router. CGNAT/double NAT may prevent connections; use WebRTC with TURN instead.

Uses the first UDP STUN URL below, or Google's default. Discovery fills only the IP; keep the TCP port you forwarded. Finding an address does not prove the port is reachable.

UPnP is optional and opens only this TCP port while hosting. Leave the address blank to use the address reported by the router. Share invitations privately: each contains access to its assigned guest hero. End hosting removes the automatic mapping; crashes may leave it until the lease expires.

Internet connection settings

Blank settings try LAN only. For internet play, enter your STUN server and optional TURN relay on both computers. No relay is provided. Credentials stay in memory for this session.
